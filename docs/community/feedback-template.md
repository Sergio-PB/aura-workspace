# N-1 Feedback Collection — Template & Process

> **Status:** Ready for founder action
> **Blocked on:** First event completed

## Collection Method

**Primary:** Direct message (Telegram/Signal/SMS) within 24 hours of the event.
**Secondary:** In-person conversation during the event (note mentally, write down after).
**Tertiary:** Group chat debrief (if the group is chatty).

## Questions

### For attendees who used the Farm (recorded/attributed points):

1. Walk me through the last time you gave someone points. What was smooth? What was annoying?
2. Did you ever want to give points but didn't? Why?
3. Did the telemetry stuff (camera, location) feel creepy or fine?
4. What would make you use this more often?

### For attendees who only used the Card (checked feed, claimed points):

1. How did it feel to see points attributed to you?
2. Did you want to react to anything in the feed? Could you?
3. What would make you open the app again tomorrow?

### For attendees who didn't use it at all:

1. What stopped you? (Too complicated? Not interesting? Forgot?)
2. What would have made you try it?

### For everyone:

1. If Aura was a person, how would you describe them?
2. Would you invite a friend? Why or why not?
3. What's the one thing we should fix before you'd use it again?

## How to Record Feedback

Create a file: `docs/community/feedback/event-1-YYYY-MM-DD.md`

Template:

```markdown
# Event 1 Feedback — [Date]

## Attendees
- [Name]: [used Farm / used Card / didn't use]
- ...

## Raw Feedback

### [Name]
- Most fun: ...
- Confusing/annoying: ...
- Would use again: [yes/no/maybe] — ...
- One thing to fix: ...

## Patterns

- [Theme that came up multiple times]
- [Theme that came up multiple times]

## Surprises

- [Something unexpected]

## Action Items

- [ ] [Fix/change based on feedback]
- [ ] [Fix/change based on feedback]
```

## What to Do With Feedback

1. **Triage:** Bugs → fix immediately. UX confusion → note for P-3/P-4 refinement. Feature requests → add to backlog, don't build yet.
2. **Share back:** Tell the group what you heard and what you're changing. Shows you're listening.
3. **Don't over-correct:** One person's complaint isn't a trend. Wait for patterns.
